# AI万有网

面向国内与海外用户的小而美工具与 API 商店。主站域名为 `www.aiwyw.com`，备案办理中，首发商品为站长自研的 markdo。

当前已接通商品和栏目、静态详情发布与回滚、存储管理、Summernote、多应用页签、邮箱账户、模拟充值/批次钱包/整单退积分、永久大版本交付和在线软件授权；新增昵称与密码自助修改、多角色菜单并集及非对称勾选的角色树、可配置双因素策略和浅色认证页面。

个人资料在“我的账户”维护，后台账号亦可从“账户安全”进入。改密校验原密码并撤销全部设备会话；角色树勾选父级不选子级，选子级补齐父级；父级不授予子菜单权限。详见[本次变更](docs/PROFILE-TREE-AUTH.md)、[身份权限说明](docs/IDENTITY-AND-ROLES.md)及[开发状态](docs/DEVELOPMENT.md)。

首页栏目入口为 **系统管理 → 配置管理 → 首页栏目**，也可从两级菜单直接进入。最多6个，支持双语名称、启停、排序、人工选品、标签和自动排序。商品资料统一在应用管理中维护；原P1的`product.markdo.*`展示配置不再作为公开数据源，旧数据库行保留，不能通过改旧展示键替代发布。

这是面向生产的实现过程，**完整V1.0尚未验收完成**。完整API计费、客服、内容运营及完整运营统计仍需继续接通；当前不开放真实收款。初始markdo仅为草稿，资料不齐不会伪装为可下载商品。

## 运行开发环境

需要 Java 17 或兼容版本、Maven 3.9，以及 Node 24.15 以上的 24.x 版本。源码编译目标为 Java 17。

在项目根目录执行：

```sh
mvn -f backend/pom.xml spring-boot:run
```

另一个终端执行：

```sh
npm ci
npm run dev
```

打开 `http://localhost:3000/install`。从后端首次启动提示复制一次性安装码，选择数据库并创建至少12位密码的管理员账号。安装码不在公开状态接口返回，安装完成后会删除并锁定安装入口。双因素策略默认开启，管理员/财务首次使用须完成验证；管理员可从配置管理关闭该策略用于应急。

本地数据库用于开发和体验。生产环境首次安装请选择已创建的空 MySQL 库；连接要求 TLS，数据库用户需要建表权限。安装失败时保留原数据库，不会清空已有用户。当前尚不提供数据库在线迁移；不能通过直接更换连接来迁移数据。

打包后也可运行 `npm start`，同时启动前后端本地预览。该命令和后端开发命令共用 `backend/data/`；不要同时启动两套服务。受限Windows桌面建议使用此入口，启动脚本已做进程级Java网络兼容处理，无需改变系统设置。

## 统一配置入口

进入 **系统管理 → 配置管理**，可设置网站、首页栏目、充值收款、积分交易、API、授权、客服、邮件、存储与安全参数。不需要修改 `application.yml`、`.env` 等运行配置文件。

运营配置持久化在数据库；敏感值经 AES-256-GCM 加密，读取接口只返回是否已设置，留空不覆盖已有值，清除需要明确勾选。保存支持版本冲突检测，批量变更在事务中执行。审计只保存操作者、配置项、时间和版本，不保存原文。

初始化数据库连接与本地加密主密钥是系统启动所需的引导资料，由安装页面写入，系统自动维护在 `data/` 中，不要求用户手工编辑。主密钥和一次性安装码设置为当前运行账户可读写。不要提交此目录；生产环境须使用独立运行账户，并备份数据库及整个 `data/`。丢失主密钥将无法解密已有配置。HTTP 只用于本机开发，生产入口应配置 HTTPS。

当前没有开放真实充值。预置二维码内容明确表示模拟测试，不指向真实收款。管理员可分别上传支付宝和微信付款码，但上传或替换图片不会打开真实资金业务。未选为模拟展示图的真实付款码只允许管理员预览。

**生效范围：** 网站展示、商品目录与发布、首页栏目、后台会话有效期、新登录限速、图片保存、SMTP 手动测试已接入实际功能；本地/对象存储上传、文件库、资源保护和短期下载已接入；模拟交易已接入；API、客服设置目前为后续模块的配置基线，随业务实现接入，不表示这些业务已经可用。部分已确认的强制安全规则禁止在界面或接口关闭。新增初始值如提醒提前3天属于可调整的实施初值，不能视为新的业务承诺。

验证器丢失恢复流程尚未交付；请在验证器内保留安全备份。正式运营前必须补齐管理员恢复流程、生产 MySQL 联测、外部服务联测与完整 V1.0 验收。

## 验证

```sh
mvn -f backend/pom.xml test
npm run typecheck
npm run build
npm run test:e2e
```

后端集成测试使用临时本地数据库；验证安装保护、MFA 权限、配置加密、原子保存与冲突、访问权限、图片校验、TOTP 防重放及会话撤销。端到端测试会创建隔离的临时服务数据目录，默认使用本机18080和3000端口，测试前关闭占用这两个端口的本项目开发服务；不要停止其他应用。

## 可维护性与人工恢复

前后端业务代码已重新排版并提供中文注释。实际数据库表、字段均带COMMENT；已存在P1表会通过幂等迁移补齐。详见 `docs/database/IMPLEMENTED-SCHEMA.sql` 与 `docs/MAINTENANCE.md`，说明密钥成套备份、草稿/发布指针关系、失败保护、审计和极端情况下的人工排查。不要直接改余额、删除历史快照或重建密钥来绕过异常。

## 本地阶段自动更新

本机Maven环境已安装。后续阶段完成后自动运行 `npm run deploy:local`，包含备份、编译、测试、运行副本切换和健康检查。双击 `start.cmd` 查看，`update-local.cmd` 更新，`stop-local.cmd` 停止；数据保留。详见 `docs/LOCAL-DEPLOYMENT.md`。

## 存储与应用编辑

在系统管理打开“存储管理”，配置本地或S3兼容对象存储后可上传图片和下载内容；应用管理的新增/编辑在独立页签进行，支持同时维护不同应用。页签右键提供左右/其他/全部关闭和未保存决策，列表支持组合筛选与服务端分页，图文使用Summernote。详见 [存储与应用编辑说明](docs/STORAGE-AND-EDITING.md)。
