# 存储管理与多应用编辑使用说明

本阶段实现真实文件上传、存储配置、资源复用、独立应用编辑页签、Summernote 图文编辑及后台组合分页。不是完整 V1.0 交付。

## 管理员操作

1. 在后台打开“存储管理 → 存储配置”。这些配置与“系统管理 → 配置管理”共享同一份数据库设置，无需修改配置文件。
2. 本地模式可直接使用。目录为服务数据目录下的受控相对子目录，默认 assets；可以在后台更改新上传目录，不支持任意系统绝对路径。点“保存存储配置”，再点“检查已保存连接”。
3. 对象存储使用 S3 兼容接口：填写 HTTPS Endpoint、Bucket、Region、Access Key、Secret Key；需要临时凭据时同时填写 Session Token。按服务商要求设置路径寻址。Bucket保持私有，不需要公开读权限；服务账户需要指定Bucket的读取信息、写入、读取、删除对象权限。
4. 密钥加密保存，后台不回显，空白保持原值，明确勾选清除才删除。切换模式只作用于新上传；原文件按上传时保存的加密连接快照访问。不要通过更改当前Bucket来搬迁旧资源。
5. 更换相同对象存储位置的密钥后，可在检查连接通过后点“同步历史连接凭据”，仅更新Endpoint、Bucket、Region、寻址方式全部一致的历史连接。此操作不会迁移文件；其他位置须保持对应历史凭据有效。
6. “外部链接”模式保留已有链接和资源，拒绝新上传。应用字段仍可选择HTTPS外链。

## 发布应用

在“应用管理”点“新增应用”或某行“编辑”，会打开独立页签。同一应用再次点编辑切换到已有页签，不开重复表单；不同应用、多个新增草稿可以同时保留。

应用图标、截图、下载内容均可上传或从文件库选择。图片支持PNG、JPG、WebP，服务器实际解码后重新保存PNG，不能通过改扩展名上传SVG/HTML。图片默认10MB、安装包默认256MB；管理员可在存储配置内修改限制。图片最长边8192且最多2500万像素。

中文、英文介绍使用 Summernote Lite，支持段落、标题、加粗、颜色、列表、表格、链接、图片、撤销与全屏。图片按钮及粘贴图片走统一存储上传；“文件库”可插入已有图片，正文引用资源地址，不内嵌base64。编辑器脚本、语言包、字体均随站点打包，不依赖CDN。

“保存草稿”保存资料和资源引用；“保存并发布”先保存、再生成静态详情并切换公开版本。失败保留旧版。下载文件的私有资源标识不会出现在公开商品JSON或静态正文里。0积分应用通过公开交付接口申请短期下载凭据，本地文件支持Range续传；对象存储跳转短时签名地址。非0积分仍沿用尚未完成的权益校验边界，本阶段不绕过收费规则。

## 页签与查询

页签右键菜单支持关闭右侧、其他、左侧、全部。固定“工作台概览”保留。涉及未保存内容时统一列出页签，可保存并关闭、放弃修改并关闭、取消。任一保存失败或上传未完成，目标页签保持打开，已成功保存的草稿不会回滚。切换页签不触发保存，也不丢弃内容；刷新/离开页面有浏览器未保存提示。未保存草稿仍在浏览器内存中，关闭整个浏览器不会自动恢复。

后台列表在服务器先组合筛选、再分页，可按关键字、上架/下架/草稿、栏目、多个标签及发布时间范围查询。多个标签全部匹配，日期包含起止日，按北京时间最近一次成功发布计算；从未发布的草稿不匹配日期条件。栏目使用当前选品规则：手工选品匹配所选ID、标签选品匹配任意栏目标签、自动热度/最新栏目匹配候选应用；后台可看草稿，公开首页仍只展示上架应用。每页10/20/50条。

## 资源保护与维护

资源状态为UPLOADING → READY；物理写入失败不返回成功。删除先锁定资源并核对引用，成功才标记DELETED，物理删除失败保留DELETE_PENDING供后台重试。正在上传的资源暂不允许删除。被草稿或任何历史发布引用的文件禁止删除，避免静态页和历史交付损坏。草稿移除图片后，已发布过的历史引用仍保护文件。

图片发布前只有运营/管理员会话可预览，首次发布引用后为公开不可变图片。安装包始终私有，不能用资源ID直接获取下载；短期凭据只存摘要并校验有效期。已公开图片可缓存，撤下应用不会自动撤销已经公开的图片。

本地自动备份包含数据库、主密钥、连接配置、assets目录及其他服务数据。S3对象正文不包含在本机备份中，须由Bucket版本管理/备份覆盖；迁移或恢复应把数据库、主密钥和对应物理文件作为同一恢复集合。严禁只删除storage_reference再删文件、手工把状态改READY、在config_enc写明文，或删除迁移记录强制重跑。暂存文件只可在服务停止、备份完成并确认无上传时清理，禁止清除整个数据目录。

## 数据结构与实现

新增storage_profile（加密历史连接）、storage_asset（文件元数据）、storage_reference（草稿与发布引用）、storage_download_ticket（短期凭据）、storage_audit（操作审计）、catalog_product_tag（当前草稿标签查询索引）。catalog_product新增last_published_at和search_text。启动迁移V003回填历史草稿索引和当前发布的时间，不改写不可变发布正文。

资源正文不放数据库；本地文件名由服务生成，下载文件按attachment/octet-stream提供。文件列表与公开商品均不返回对象存储密钥、内部路径或连接快照。配置、目录、存储审计汇入“操作记录”。中文注释表结构见database/IMPLEMENTED-SCHEMA.sql，事务和失败恢复说明见对应Java/Vue源文件。
