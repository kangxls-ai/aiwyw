# 内容运营与静态发布

文章、教程、FAQ、案例已接入实际数据库和发布流程。“文章与教程”维护前两类，“FAQ 与案例”维护后两类；首页页脚“文章与教程”进入公开内容列表。列表按实际发布快照分页，可按类型和中英文标题查询。草稿仅后台可见。

## 编辑和发布

1. 新增内容，填写中文标题、固定公开地址、摘要和正文。富文本使用 Summernote，粘贴/上传图片复用存储管理，支持本地与 S3 兼容对象存储。上传结束后才能保存发布。
2. 保存草稿不会改动已发布版本。中文摘要和正文是发布必填项；英文标题和正文须同时填写，或同时留空并回退中文。公开地址首次发布后不可变更。
3. 保存并发布先生成中英文不可变 HTML、SHA256 和快照，再在数据库事务内切换公开指针。写入失败不切换，旧版继续生效。请求携带版本号，旧版本编辑返回冲突，不能静默覆盖。
4. 公开地址为 `/articles/{slug}`，英文为 `?lang=en`。关闭 JavaScript 仍可阅读完整正文，图片和排版不依赖客户端读取正文接口。页面通过 ETag 重新验证，内存最多缓存30秒；本进程发布和下架主动清理缓存。
5. 下架后内容详情返回404，公开列表与站点地图移除。已发布内容不物理删除，保留历史快照与图片引用；未发布草稿可删除。

已发布正文使用浅色独立阅读版式，适配手机。公开列表桌面三列、手机一列。操作表单采用 Element Plus、左右标签及既有列表排序约定；编辑状态接入工作台未保存提示。

## 权限及 SEO

文章与教程需要 `articles` 菜单授权，FAQ 与案例需要 `faq`，SEO 设置需要 `seo`。创建、读取草稿、修改、发布、下架和删除均由服务端按内容类型校验；角色父级不带来子级权限。跨内容分类调整须同时具备两类菜单权限。

SEO 页面只开放中英文网站描述和搜索引擎索引开关，不授予读取系统密钥的权限。所有设置仍持久化在统一配置管理中，支持版本冲突检测和审计。内容静态页包含标题、摘要、canonical、已提供语言的 hreflang 及 Article/FAQPage JSON-LD。结构化数据经过 JSON 编码与 HTML 安全转义，富文本经服务端白名单净化。

`/sitemap.xml` 只包含已发布商品、已发布内容和公开入口；`/robots.txt` 阻止后台、账户及 API 路径。索引关闭时站点地图不列出地址，robots 禁止抓取，内容静态页即时增加 `X-Robots-Tag: noindex, nofollow`。robots 不代替访问控制，也不能保证搜索引擎立即移除历史收录。既有静态页的标题/域名等快照资料需要重新发布才更新。此功能提供可抓取内容，不承诺搜索排名或 AI 引用。

## 数据及维护

新增 `content_document` 与 `content_publication`，字段和表均带中文说明，结构见 [CONTENT-SCHEMA.sql](database/CONTENT-SCHEMA.sql)。正文存储在数据目录 `content-pages/`，须随数据库和主密钥成套备份。发布沿用商品全局保护行，再锁资源，避免与图片删除并发；`CONTENT_DRAFT`、`CONTENT_PUB` 引用保护媒体，不能手工删除被引用资源。

发布失败可能留下尚未引用的不可变文件，应先核查数据库发布记录再人工清理，不能直接删整个内容目录。校验失败返回503，不回退到未发布草稿；先检查快照、文件和 SHA256，恢复成套备份或重新发布。当前提供历史留存，尚无内容历史版本回滚界面；商品的既有回滚功能不受影响。

当前部署为单个后端进程；多实例发布失效通知、分布式锁/缓存及 CDN 失效仍属于生产扩展验收。完整 API 套餐/计费、客服聊天和完整运营统计仍待后续模块，不能把本阶段视为完整 V1.0 已验收。
