# 界面与导航优化（2026-11-05）

## 使用变化

- 字体统一为页面标题26px（移动端24px）、区块标题20px、次级标题16px、正文/菜单/表头/表单名称/按钮14px、辅助提示13px、状态标签12px；正文常规字重、标签和操作中等字重、标题适度加粗。旧样式的小字统一使用辅助字号变量。
- 登录入口及后台登录页提供居中、间距与分隔一致的登录/注册/找回密码入口；表单名称继续位于输入框左侧，长名称自动换行，按钮文字居中。列表操作列居中，弹窗操作区统一间距。
- API管理的新增和编辑使用独立工作页签，重复编辑同一服务切换到已打开页签；多个服务或新增草稿各自保留输入。保存后更新名称与版本并刷新列表。关闭/右键批量关闭沿用保存、放弃、取消机制，包含上游凭据的表单不会写入浏览器持久存储。
- 我的账户按充值订单、积分流水、我的资源、退款申请、站内通知、个人资料与安全、API与客服拆分。充值表单和订单放在一起，批次放在积分流水，邮件偏好放在通知；资料表单切换页签保留当前输入。
- 顶部导航先按后台栏目顺序展示，API服务固定在最后，新增或重排栏目不会把API挤到中间。窄屏自然换行，保持相同阅读顺序。
- 文章与教程在“首页栏目”维护双语名称/说明、图标、顺序、启停；顶部直接跳转文章列表，列表标题同步栏目名称。文章栏目是导航入口，不生成应用卡片，不占六个应用展示区的额度；最多一个，可删除后重新添加。
- 角色列表仅展示创建时间、名称、操作；进入编辑弹窗查看与维护菜单树。

## 数据与发布

`V008_ARTICLE_NAV`在目录锁内一次性增加文章栏目与迁移标记，不修改既有应用栏目、商品或交易资料；管理者后续删除/停用不会被重启覆盖。栏目沿用`home_section.config_json`，`mode=ARTICLES`表示文章导航，其他模式保持原含义。服务端仍独立校验六个应用栏目及文章唯一性。

公开栏目增加`kind`和受控内部`href`，不接受任意外部跳转。文章与应用的筛选入口分开，应用列表不会出现文章栏目筛选项。

公共视觉资源为`web/public/ui-theme.css`。已发布详情在文件完整性检查后附加同源样式引用；不改历史文件和购买快照、不重新查询详情接口、保留原脚本CSP摘要。文章响应使用新的ETag后缀，应用ETag按最终响应计算；CSP仅增加同源样式许可。富文本作者正文的字号、强调和图片不被统一界面规则覆盖。
