# 首页与后台工作台原型 V3

2026年11月4日。此版本延续 V2 原型，商品、交易、客服与 API 的完整业务阶段保持不变。

## 查看入口

- `/preview/directory`：新版首页。
- `/preview/admin`：无需安装或登录的独立后台布局演示，使用示例内容，不连接真实配置管理接口。
- `/preview/apps/markdo`：静态化应用详情示例。
- `/admin`：已实现基础功能的真实后台，仍需登录与 MFA。菜单中尚未实现的业务清楚标为待接入。

## 首页交互

保留站长推荐、最新上架、热门下载、热门点击四区及搜索。电脑宽屏一行10款，窄屏自动换行。应用卡片加高，底部显示浏览数、下载数和独立的“查看详情”。图标和名称可打开详情；鼠标在卡片内或键盘聚焦卡片时，图标上浮出下载按钮。触屏设备直接显示下载按钮，不依赖悬停。按钮沿用 V2 免费下载和积分模拟交互，文件仍为演示说明，二维码仍为模拟图片。

## 后台布局与菜单

顶部浅色 banner 展示品牌，右上角显示用户、访问网站和账户菜单。下方左侧为可折叠两级菜单，右侧为工作区。页签位于工作区上方，同一菜单只打开一个页签，重复点击切换到已打开页签。工作台固定，其余页签可关闭；关闭当前页签切换相邻页签，关闭其他页签保持当前工作区。

菜单覆盖工作台、商品管理、交易管理、API 服务、客服与反馈、内容运营、用户与权限、系统管理。系统管理保留配置管理、存储管理、邮件设置、操作记录和账户安全入口。可运营设置仍应集中从配置管理维护，独立管理入口用于相应资源和动作。

真实配置管理支持切换页签保留未保存表单，关闭有修改的页签时先提示确认。关闭后再次打开创建新的页面实例。后台布局演示提供同类可操作交互；其表单和模块数据是本次页面体验状态，不冒充后台持久保存。

## 详情静态化

构建时为30个示例应用预生成完整 HTML 与页面数据文件。构建后校验页面存在、包含应用名及介绍正文，并生成 `/preview/static-manifest.json`，记录构建版本、路径与内容摘要。后台演示的“商品管理 → 发布与静态化”展示该清单。

公开原型详情的正文、标签、截图和展示统计从静态内容读取，不请求后台商品查询接口；关闭 JavaScript 仍能阅读介绍。版本清单用于验证本次构建产物，不是已接通的商品发布 API。

正式商品维护阶段需接通“保存草稿 → 发布快照 → 生成静态产物 → 校验 → 原子切换发布版本 → 清理缓存”的后台操作，并支持失败保留旧版本、下架失效与回滚。运营者点击发布即可，不要求手动编辑配置文件。用户余额、登录身份、购买权益、实时价格校验和下载授权继续由服务端处理，不能以静态页面或演示浏览器状态替代。

## 验证记录

前端类型检查、生产构建通过。真实后台浏览器回归2项通过，覆盖安装、登录、MFA、配置保存、页签切换保留输入、未保存关闭提示、敏感字段、付款码上传、审计及退出会话。
