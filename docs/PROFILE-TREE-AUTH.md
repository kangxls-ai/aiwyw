## 使用与规则

“我的账户”和后台“账户安全”均提供个人昵称及密码维护。昵称1—40字；修改后刷新当前身份显示。改密码需当前密码、新密码和确认密码，新密码至少12字符且不得与旧密码相同。服务端独立校验旧密码、频控及账户状态；密码摘要更新、全部会话撤销、未使用RESET令牌作废与审计在同一账户锁事务内完成。成功后返回登录页；密码、确认值不进浏览器存储或审计。高权限角色在策略开启时仍需先完成双因素认证，不通过普通个人接口绕过。

角色授权使用Element Plus树形组件，父节点独立选择，不自动勾选子节点；选中子节点自动补齐父节点。仍有已选子节点时不能取消其父级；取消最后一个子节点后保留父级独立选择，父级可以再手动取消。服务端保存时执行同样的补父规则。父级键采用group:前缀，仅用于保存树状态，从实际会话菜单权限中剔除，因此仅勾选分组不能访问组内功能。旧角色只存子菜单时读取自动补齐父节点，不改变其既有授权。

登录、邮箱注册、忘记密码及重置页采用首页灰白/浅紫色调。后台登录复用首页品牌标识及配色，邮箱账户入口使用首页目录布局。保留移动端适配、左右标签和合理控件宽度。
