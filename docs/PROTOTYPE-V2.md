# 首页与商品原型 V2

2026年11月4日，按用户要求迭代。此文档记录交互原型，不代表交易、商品维护或实际支付业务已上线。

## 页面与布局

- `/preview/directory`：检索、站长推荐、最新上架、热门下载、热门点击，按此顺序显示。电脑每行10个图标与名称，窄屏自动换行。四个区域均有“更多”。
- `/preview/apps?section=recommended`：对应区域的完整应用列表，支持名称及功能搜索、多标签筛选、分页。电脑三列、平板两列、手机一列，每页9款。筛选与页码保存在URL，修改筛选重置为第一页。
- `/preview/apps/markdo`：应用详情。顶部加长应用信息区，中部可切换和放大的截图，下部展示包含标题、段落、列表、图片、引用及更新说明的富文本介绍。

列表卡片左侧图标及名称，右侧描述、标签、上传时间、下载次数与浏览次数；右下角独立“查看详情”。点击卡片其他部分触发下载，点击详情只导航，不下载也不扣积分。返回列表保留来源筛选和页码。

## 模拟下载与积分

0积分应用直接触发浏览器下载。文件为明确标识的原型演示说明，不冒充真实安装包。

非0积分且未兑换应用打开模拟二维码弹窗，显示所需积分、演示余额、本次需充值及扣除数量。初始演示余额30积分。余额充足直接确认扣分；不足按1元10积分、整元充值补足后再扣积分。按钮处理期间禁用，避免重复执行。同一应用兑换后保留演示权益，再次下载不重复扣分。

演示余额、权益、浏览下载增量和流水保存在独立浏览器存储键`aiwyw-directory-prototype-v2`，跨页面和刷新保留。头部“演示积分”可查看充值与兑换流水，也可重置体验。所有状态与服务端账户及真实资金隔离，模拟二维码不指向真实收款。

## 内容来源与后续接入

markdo名称为用户指定的真实首发商品，其功能、版本、价格和截图尚未提供。当前标签、统计、价格、截图占位及图文示例用于设计确认，未认定为正式商品事实。截图使用清楚标识的界面占位示意。

原型采用共享示例数据供三个页面保持一致。正式功能将从后台商品维护读取图标、名称、描述、标签、价格、上传时间、截图和富文本；区域展示、推荐设置及排序参数仍需接入系统管理的配置入口，不要求运营者编辑源码文件。
